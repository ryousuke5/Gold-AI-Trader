# XM GOLD# Empirical Spread Cost Model (Research Only)

Updated: 2026-11-13 (JST)

## Decision and scope

This model adds a time-varying, account-server-specific spread estimate to historical research backtests. It does not change GOLD V2 Strict production settings, V19, Render, Supabase, or any order path.

The model is a **historical proxy scenario**, not a claim that XM's exact spread was observed at every historical 2021-2026 signal. The source quote log is a recent October-November 2026 sample. For older BID-only price history, the model maps each historical UTC timestamp to the XM server-local hour using `Europe/Nicosia` (including daylight-saving transitions), then applies the selected empirical percentile for that account server and hour.

## Model behavior

- Each entry uses the profile quantile for the entry bar's server-local hour.
- Each exit uses the profile quantile for the exit bar's server-local hour. The entry and exit spread may therefore differ.
- Entry is still BUY at Ask + adverse slippage / SELL at Bid - adverse slippage.
- The BID-based stop/target trigger rules and correct executable exit sides remain unchanged.
- The entry spread is used to calculate planned effective initial risk. Realized exit spread is applied separately to realized P/L, so an unexpectedly wider exit spread can make the realized loss worse than -1R.
- A research spread gate of 0.50 price units rejects entries when the selected hourly quantile exceeds 0.50. This gate is a research simulation input, not a change to the live EA.
- If a local-hour bucket is missing or has fewer than 100 observations, the account's global percentile is used and the ledger records the fallback source.
- No unknown account-server fallback is allowed. The requested profile must exist.

## Cost scenarios

The empirical scenarios generated by the backtest are:

| Scenario | Spread estimate | Slippage per side | Account profile |
|---|---|---:|---|
| xm_demo_p50 | Hourly P50 | 0.05 (assumed) | XMTrading-Demo 6 |
| xm_demo_p90 | Hourly P90 | 0.05 (assumed) | XMTrading-Demo 6 |
| xm_demo_p95_stress | Hourly P95 | 0.10 (assumed stress) | XMTrading-Demo 6 |
| xm_real_p90 | Hourly P90 | 0.05 (assumed) | XMTrading-Real 11 |

Fixed spread 0.50 / slippage 0.05 and fixed conservative spread 0.75 / slippage 0.10 are retained as comparability scenarios.

**Slippage has not been estimated from actual order fills.** The 0.05 / 0.10 values are assumptions. The quote logger does not produce fills. **Commission, swap and financing are not yet modeled** because a verified account-currency schedule and actual demo execution records have not been supplied. Therefore this is an empirical spread model, not yet a complete all-in trading-cost model.

A separately collected 2026-11-10 quote export has no account_server field; it is not mixed into Real or Demo profiles. It is kept as an unattributed cross-check only.

## Interpretation limits and required follow-up

1. Recent-hour percentiles applied to 2021-2026 BID proxy history are scenarios, not observed historic XM spreads.
2. Five-year historical source bars remain Dukascopy XAUUSD BID, not XM-native GOLD# historical BID/ASK ticks.
3. Same-bar stop/target sequencing still uses conservative STOP-first bar logic; quote/tick replay is not available for every historical period.
4. Before calling costs fully calibrated, collect actual Demo 6 entry/exit fills and verify signed slippage, commission, swap and financing in account currency. Keep manual demo probes separate and supervised; no probes are authorized by this research change.
5. No cost-model result authorizes demo or live orders. V19 remains signal-only; production execution gates remain OFF.
